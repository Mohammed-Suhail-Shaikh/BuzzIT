# 0001 — Web marketing home (landing)

## Context

First slice of the BuzzIT **website**: a **home landing page** that explains **the idea** and **how we plan on providing the service to our users** (product story, not authenticated app chrome). Visual language must follow the project palette defined in [`docs/buzzit_palette.html`](../../buzzit_palette.html) (neutrals, violet/blush/amber/mint, Syne + DM Sans, border and gradient patterns as documented there).

## Requirements (verbatim from prompt)

- Build the **website part first**.
- The website will have a **home landing page** having the **description of the idea** and **how we plan on providing the service to our users**.
- Apply colors from **`docs/buzzit_palette.html`** for the project.

| Path | Role |
|------|------|

## Phases

Single phase: **static marketing UI** in `web/` only. Future features can add router routes, auth, and API client under the same app.
